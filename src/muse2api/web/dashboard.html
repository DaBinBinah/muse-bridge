客户端接入指南：如何把密钥添加到 CC Switch / Codex CLI（点击展开）

方式一：CC Switch（推荐，图形界面）

  1. 打开 CC Switch → 供应商 → Codex 分栏 → 添加供应商；
  2. Base URL 填 ，API Key 粘贴上面创建的密钥（m2a- 开头）；
  3. 模型填 gpt-4o 等别名（以 GET /v1/models 返回为准），保存后切换到该供应商即可。

方式二：Codex CLI
